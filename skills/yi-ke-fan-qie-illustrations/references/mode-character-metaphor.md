# 模式 A：番茄女孩怪诞隐喻

## 用途

个人经验、方法论、判断、创作者状态和输入—处理—输出。没有明确指定时优先考虑此模式。

## 画面规则

- 正文插图默认 16:9 纯白横图，黑色轻微抖动线稿，大量留白。手机录屏中嵌图时按 `mobile-knowledge.md` 选择更紧凑的比例，不把横图默认值强套进竖屏。
- 使用“知识形象”，上传角色母版；保留额心痣、卷发外轮廓、番茄徽章、服装和红鞋。
- 女孩必须亲手完成核心动作，如转动、缝合、筛选、托住、拆开或修补。
- 主物件是一个原创的低科技怪装置；只选 1–2 种物件，不拼成复杂机器展览。
- 角色与主物件合计占画面约 40%–60%。人物不是半屏头像，也不是角落贴纸。
- 黑线为主；深海军蓝留给服装，橙色留给动作路径，红色留给徽章和一个结果。

## 表情

默认专注、思考、轻微困惑、无奈或发现问题；不要每张都甜笑或举手庆祝。面部仍需与母版同一人，但腮红减淡、眼睛不继续放大。

## 禁止

- 不出现小黑、独立番茄吉祥物或第二个人物。
- 不复用传送带、素材鱼、盖章工具箱等已知案例构图。
- 不画成儿童海报、贴纸合集、商业矢量吉祥物或满屏蜡笔填色。
- 不让浓密头发遮住手、工具或核心连接关系。
