# 模式 D：实物微人

## 用途

品牌封面、生活观察、产品或物件驱动的轻内容。只有主题确实有一个合适实物时才选择。

## 画面规则

- 一个真实摄影质感的物件作为大主体，通常是番茄，也可使用文章中的核心物件。
- 纯白或浅白棚拍背景，真实接触阴影仅保留在实物下方。
- 3–6 个极简、无脸、无服装细节的黑线微人围绕实物完成一个协作动作。
- 微人不是番茄女孩的缩小版；此模式的品牌锚点来自真实番茄红、深海军蓝和动作气质。
- 黑线微人与实物材质必须明确分层：实物保持摄影感，微人保持二维原始线稿。

## 禁止

- 不使用任何真实茶饮品牌的 logo、包装、角色、口号或可识别商业装潢。
- 不出现完整番茄女孩、独立番茄脸吉祥物或 3D 卡通工人。
- 不堆叠多个实物英雄，不做商品广告式满版排布。
