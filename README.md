# 一颗番茄 · 正文配图 Skill

把文章中的观点、步骤和状态转成中文知识插图。工作流提供番茄女孩动作隐喻、极简线条、步骤解释、实物微人四种视觉路线，并带构图和质检参考。

## 使用

```bash
npx -y skills add zseissol-debug/yi-ke-fan-qie-illustrations
```

需要支持 Skill 的 AI Agent 和可用的图像生成能力。示例：“用步骤解释模式，为这段文章规划一张正文插图。” Skill 用于指导创作，不保证图片中文字或细节一定正确；生成后仍需人工检查。

番茄女孩母版随仓库公开展示，但角色及形象权利保留，不因代码开源而授予复用许可。使用该角色前须取得权利人许可；使用者也可自行准备有权使用的角色图并调整工作流。详见 [素材与角色说明](ASSET-NOTICE.md)。

本次安装验证使用 `skills` 1.7.4；该版本声明需要 Node.js 22.20.0 或更高。
